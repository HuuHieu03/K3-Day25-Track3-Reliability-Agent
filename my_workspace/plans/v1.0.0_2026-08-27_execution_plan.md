## 2. Lộ trình Triển khai Từng Giai đoạn (Step-by-Step Roadmap)

### 🔹 Phase 1: Circuit Breaker Module (`circuit_breaker.py`)
- **Mục tiêu**: Xây dựng trọn vẹn máy trạng thái 3 pha `CLOSED` / `OPEN` / `HALF_OPEN`.
- **Hàm cần triển khai**:
  - `allow_request()`: Cổng kiểm tra điều kiện cho phép gọi request dựa trên state và timeout.
  - `call(fn, *args, **kwargs)`: Wrapper thực thi hàm có bắt lỗi và ghi nhận trạng thái.
  - `record_success()`: Đặt lại `failure_count`, tăng `success_count`, chuyển về `CLOSED` khi đạt `success_threshold`.
  - `record_failure()`: Tăng `failure_count`, phân nhánh `if/elif` chính xác cho `HALF_OPEN` (`probe_failure`) và ngưỡng lỗi (`failure_threshold_reached`).
- **Test xác minh**: `uv run pytest tests/test_circuit_breaker.py -v` (11/11 tests PASS).

---

### 🔹 Phase 2: Semantic Cache & Privacy Guardrails (`cache.py`)
- **Mục tiêu**: Xây dựng bộ đệm tương đồng ngữ nghĩa N-gram Cosine và kiểm soát bảo mật.
- **Hàm cần triển khai**:
  - `ResponseCache.similarity(a, b)`: Tính Cosine Similarity trên Character 3-Grams + Word Tokens.
  - `ResponseCache.get(query)`: Kiểm tra Privacy Bypass, TTL Eviction, Cosine Matching và False-Hit Detection.
  - `ResponseCache.set(query, value, metadata)`: Lưu trữ có kiểm tra Privacy Guardrail.
- **Test xác minh**: `uv run pytest tests/test_cache.py -v` (9/9 tests PASS).

---

### 🔹 Phase 3: Gateway Routing Pipeline (`gateway.py`)
- **Mục tiêu**: Triển khai luồng điều phối tích hợp toàn bộ hệ thống.
- **Hàm cần triển khai**:
  - `ReliabilityGateway.complete(prompt)`:
    1. Kiểm tra Cache trước tiên (nếu trúng $\rightarrow$ trả về `route="cache_hit:..."`).
    2. Duyệt chuỗi Providers qua Circuit Breaker (`route="primary"` hoặc `route="fallback"`).
    3. Trả về degraded response nếu toàn bộ provider thất bại (`route="static_fallback"`).
- **Test xác minh**: `uv run pytest tests/test_gateway_contract.py -v` (4/4 tests PASS).

---

### 🔹 Phase 4: Chaos Simulation & Metrics Export (`chaos.py`, `metrics.py`)
- **Mục tiêu**: Đo lường khả năng chịu tải và khả năng phục hồi của hệ thống.
- **Hàm cần triển khai**:
  - `chaos.py`: `run_scenario()` và `calculate_recovery_time_ms()`.
  - `metrics.py`: `write_csv()`.
- **Xác minh**: Chạy `uv run python scripts/run_chaos.py` sinh ra `reports/metrics.json` và `reports/metrics.csv`.

### 🔹 Phase 5: Distributed Redis Cache (`cache.py`)
