## 2. Thiết kế Chi tiết Request Routing Pipeline

```mermaid
flowchart TD
    Req([Prompt Request]) --> Step1{1. Check Cache}
    Step1 -- Cache Hit (score >= threshold) --> RetCache([Return GatewayResponse\nroute='cache_hit:score'\ncache_hit=True\nlatency=0, cost=0])
    Step1 -- Cache Miss / None --> Step2[2. Iterate Providers in Order]
    
    Step2 --> GetBreaker[Get CircuitBreaker for Provider]
    GetBreaker --> TryCall{breaker.call\nprovider.complete}
    
    TryCall -- Success --> StoreCache[Store in Cache\nif cache is active]
    StoreCache --> RetSuccess([Return GatewayResponse\nroute='primary' or 'fallback'\nprovider=name\nlatency, cost])
    
    TryCall -- ProviderError / CircuitOpenError --> SaveError[Save last_error]
    SaveError --> HasMore{More providers?}
    HasMore -- Yes --> Step2
    HasMore -- No --> Step3([3. Return Static Degraded Fallback\ntext='The service is temporarily degraded...'\nroute='static_fallback'\nerror=last_error])
```

## 3. Quy chuẩn Thuộc tính Phản hồi (GatewayResponse Specs)

1. **Cache Hit**:
   - `route`: `f"cache_hit:{score:.2f}"`
   - `provider`: `None`
   - `cache_hit`: `True`
   - `latency_ms`: `0.0`
   - `estimated_cost`: `0.0`
2. **Primary Provider (Provider đầu tiên index 0)**:
   - `route`: `"primary"`
   - `provider`: `provider.name`
   - `cache_hit`: `False`
   - `latency_ms`: `resp.latency_ms`
   - `estimated_cost`: `resp.estimated_cost`
3. **Fallback Provider (Index > 0)**:
   - `route`: `"fallback"`
   - `provider`: `provider.name`
4. **Static Degraded Fallback (Toàn bộ thất bại)**:
   - `text`: `"The service is temporarily degraded. Please try again soon."`
   - `route`: `"static_fallback"`
   - `provider`: `None`
   - `error`: `last_error`
