## 2. Mô hình Dữ liệu (Redis Data Model)

1. **Namespace & Key**: `"{prefix}{query_hash}"` (ví dụ: `rl:cache:a1b2c3d4e5f6`).
2. **Cấu trúc Dữ liệu (Redis Hash)**:
   - Field `"query"`: Chuỗi truy vấn gốc của người dùng.
   - Field `"response"`: Chuỗi phản hồi từ LLM Provider.
3. **Vòng đời Tự động**: Thiết lập `EXPIRE key ttl_seconds` sau mỗi thao tác lưu trữ (Redis tự động thu hồi bộ nhớ, không cần dọn dẹp thủ công).

## 3. Thiết kế Chi tiết Phương thức

### 3.1. `set(self, query: str, value: str, metadata: dict[str, str] | None = None) -> None`
1. Kiểm tra Privacy Guardrail: `if _is_uncacheable(query): return`.
2. Tạo key: `key = f"{self.prefix}{self._query_hash(query)}"`.
3. Ghi hash vào Redis: `self._redis.hset(key, mapping={"query": query, "response": value})`.
4. Thiết lập TTL: `self._redis.expire(key, self.ttl_seconds)`.

### 3.2. `get(self, query: str) -> tuple[str | None, float]`
1. Kiểm tra Privacy Guardrail: `if _is_uncacheable(query): return None, 0.0`.
2. **Kiểm tra Exact Match (Tra cứu nhanh $O(1)$)**:
   - `exact_key = f"{self.prefix}{self._query_hash(query)}"`.
   - `resp = self._redis.hget(exact_key, "response")`.
   - Nếu tồn tại: Kiểm tra False-hit, ghi log nếu vi phạm, ngược lại trả về `(resp, 1.0)`.
3. **Quét Tương đồng Ngữ nghĩa (Similarity Scan)**:
   - Quét qua `self._redis.scan_iter(f"{self.prefix}*")`.
   - Lấy `data = self._redis.hgetall(key)`.
   - Tính toán Cosine Similarity qua `ResponseCache.similarity(query, cached_query)`.
   - Tìm bản ghi có `best_score >= self.similarity_threshold`.
   - Kiểm tra `_looks_like_false_hit()`, ghi log `self.false_hit_log` nếu vi phạm.
   - Trả về `(best_response, best_score)` hoặc `(None, best_score)`.
